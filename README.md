# Interview Prep 🚀

DSA, HackerRank, and backend interview preparation for software engineering roles.

## 📌 About This Repository

This repository tracks my hands-on preparation for software engineering
interviews. Every solution here was solved and pushed as part of real
practice — no filler commits, no shortcuts.

Each solution file includes:
- The problem name and its pattern/category
- My approach and reasoning
- Time and space complexity analysis
- A working Python solution
- A key takeaway I want to remember
